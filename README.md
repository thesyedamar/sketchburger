# SketchBurger

SketchBurger is a modern burger restaurant website built with Next.js and TypeScript. It presents the brand, menu, and ordering experience in a clean interface designed for quick browsing and conversion.

## Highlights

- Responsive restaurant website for desktop and mobile
- Menu-focused layout for browsing food items clearly
- Polished frontend presentation suitable for a real food business
- Live deployment for easy client review

## Live Demo

https://sketchburger.vercel.app

## Tech Stack

- Next.js
- TypeScript
- React
- Modern CSS frontend styling
- Vercel

## Run Locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000` in your browser.

## Project Focus

This project demonstrates client-ready frontend development for a food business: clear visual hierarchy, responsive layout, and a practical product experience that can be adapted for real restaurant ordering workflows.
